# A Little Universe Made for Babe 💗
Run locally: open index.html, or `python3 -m http.server` and visit http://localhost:8000
Publish: drag this folder onto app.netlify.com/drop (or GitHub Pages / Cloudflare Pages), then share the link on WhatsApp.
Edit name/date/sender: top of js/main.js (birthdayConfig). Photos: replace assets/images/memory1-6.jpg (or edit filenames in js/animations.js, memories()).
## Stickers (NOT included, genuine Bubu & Dudu art is copyrighted)
Add your own legitimately obtained files to assets/stickers/: bubu-happy.png, dudu-happy.png, bubu-hugging-dudu.png, bubu-heart.png, bubu-kiss.png, bubu-dudu-love.gif. Labeled placeholders show until you do.
## Dairy Milk: the bar is an unofficial purple illustration. Add assets/images/dairy-milk.png only if you have a rights-cleared image.
## Audio: music and sound effects are synthesized in the browser (no files). Music stays off until she taps 🎵.
## Test checklist: envelope opens, every Back/Continue works, memory hover + photo preview, letter types out, 5 Bubu & Dudu scenes + sticker taps, wish, blow (button and mic), cut, chocolate + one more, open heart, replay.
